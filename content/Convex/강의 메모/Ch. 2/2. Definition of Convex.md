# Convex sets

|     |                            |                                                                                                    |
| --- | -------------------------- | -------------------------------------------------------------------------------------------------- |
|     | line                       | $\theta \in \mathbb{R} \implies x = \theta x_{1} + (1-\theta)x_{2}$                                |
|     | line segment               | $0 \leq \theta \leq 1 \implies x = \theta x_{1} + (1-\theta)x_{2}$                                 |
|     | affine set                 | $x_1, x_2 \in C, \quad \theta \in \mathbb{R} \implies \theta x_1 + (1-\theta)x_2 \in C$            |
|     | convex set                 | $x_1, x_2 \in C, \quad 0 \le \theta \le 1 \implies \theta x_1 + (1 - \theta)x_2 \in C$             |
|     | cone                       | $x \in C, \quad \theta \ge 0 \implies \theta x \in C$                                              |
|     | convex cone                | $x_1, x_2 \in C, \quad \theta_{1}, \theta_{2} \ge 0 \implies \theta_{1} x_1 + \theta_{2}x_2 \in C$ |
|     | hyperplane                 | $\{ x \| a^T x = b \} \quad (a \neq 0)$                                                            |
|     | halfspace                  | $\{ x\|a^T x \leq b \} \quad (a \neq 0)$                                                           |
|     | ball                       | $B(x_c, r) = \{x \mid \|x - x_c\|_2 \le r\}$                                                       |
|     | ellipsoid                  | $\mathcal{E} = \{x \mid (x - x_c)^T P^{-1} (x - x_c) \le 1\}$                                      |
|     | norm                       |                                                                                                    |
|     | norm ball                  |                                                                                                    |
|     | norm cone                  |                                                                                                    |
|     | ployhedra                  |                                                                                                    |
|     | positive semidefinite cone |                                                                                                    |

# Combination

|        | 수식 ($\sum \theta_i x_i$)              | $\theta_i$에 대한 조건 | 합($\sum \theta_i$) 조건 |
| ------ | ------------------------------------- | ----------------- | --------------------- |
| Affine | $\theta_1 x_1 + \dots + \theta_k x_k$ | 없음 (음수 가능)        | $\sum \theta_i = 1$   |
| Convex | $\theta_1 x_1 + \dots + \theta_k x_k$ | $\theta_i \ge 0$  | $\sum \theta_i = 1$   |
| Conic  | $\theta_1 x_1 + \dots + \theta_k x_k$ | $\theta_i \ge 0$  | 없음                    |
