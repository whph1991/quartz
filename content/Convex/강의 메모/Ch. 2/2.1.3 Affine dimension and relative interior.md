# Overview
집합의 차원을 정의하고 내부(interior) 개념을 확장하기 위한 **아핀 차원(Affine dimension)** 과 **상대적 내부(Relative interior)** 를 다룹니다.

---
## 2.1.3 아핀 차원과 상대적 내부 (Affine Dimension and Relative Interior)
많은 볼록 집합들이 전체 공간($\mathbb{R}^n$)보다 낮은 차원의 부분 공간에 놓여 있는 경우가 많습니다. 이를 정확히 다루기 위해 일반적인 차원과 내부의 개념을 확장합니다.

### 1. 아핀 차원 (Affine Dimension)
집합 $C$의 **아핀 차원**은 그 집합의 **아핀 헐(affine hull)** 의 차원으로 정의됩니다.

- **정의:** $\text{dim}(C) = \text{dim}(\text{aff } C)$
- **예시:** 3차원 공간($\mathbb{R}^3$) 내에 있는 단위 원판(unit disk) ${x \in \mathbb{R}^3 \mid x_1^2 + x_2^2 \le 1, x_3 = 0}$을 생각해 봅시다.
    - 이 집합은 3차원 공간에 있지만, 아핀 헐은 $x_3=0$인 평면입니다.
    - 따라서 이 집합의 아핀 차원은 **2**가 됩니다.

### 2. 상대적 내부 (Relative Interior)
일반적인 위상 수학에서의 **내부(interior)** 는 집합이 전체 공간을 차지하지 못하면 공집합이 되는 한계가 있습니다. 이를 해결하기 위해 ==아핀 헐 내에서의 내부를 정의한 것이 **상대적 내부**==입니다.

- **정의:** $\text{relint } C = \{x \in C \mid B(x, r) \cap \text{aff } C \subseteq C \text{ for some } r > 0\}$ 
- **의미:** 점 $x$를 중심으로 하는 아주 작은 공($B(x, r)$)을 잡았을 때, **아핀 헐에 속하는 부분만** 집합 $C$ 안에 포함되면 됩니다.

### 3. 상대적 경계 (Relative Boundary)
- 집합의 폐포([[Closure]])에서 상대적 내부를 뺀 부분으로 정의합니다.

    - **정의:** $\text{relbd } C = \text{cl } C \setminus \text{relint } C$
    - **의미:** 집합의 전체 껍데기($\text{cl } C$)에서, 아핀 헐 기준으로 안쪽에 있는 점들($\text{relint } C$)을 제외한 나머지 점들을 말합니다.

상대적 경계를 이해하려면 왜 일반적인 **Boundary($\text{bd } C$)** 만으로는 부족한지를 먼저 알아야 합니다.
### 왜 '상대적'인가? (The Motivation)
3차원 공간($\mathbb{R}^3$)에 떠 있는 **종이 한 장($C$)** 을 상상해 보세요.

1. **일반적인 경계 ($\text{bd } C$):** 종이 위의 **모든 점**이 경계가 되어버립니다. 왜냐하면 종이는 두께가 없어서, 종이 위의 어떤 점에서도 아주 작은 3차원 공을 그리면 반드시 종이 밖(공기 중)으로 나가기 때문입니다.    
2. **이게 왜 문제인가?** 우리는 직관적으로 종이의 '테두리'만 경계라고 부르고 싶지, 종이 한복판을 경계라고 부르고 싶지 않습니다.

따라서 **"전체 공간이 아니라, 그 집합이 살고 있는 아핀 헐(Affine Hull) 안에서만 따져보자"** 는 것이 상대적 경계의 핵심입니다.

### 4. 왜 이 개념이 중요한가?
- **연속성:** 볼록 함수는 자신의 도메인의 **상대적 내부**에서 항상 연속입니다. 도메인의 경계에서는 불연속일 수 있지만, 내부에서는 안정적인 성질을 가짐을 보장합니다.
- **최적화 조건:** 많은 최적화 알고리즘이나 이론(예: Slater's condition)에서 "상대적 내부에 점이 존재해야 한다"는 제약 조건을 사용하여 문제의 풀이 가능성을 판단합니다.

---
### 5. 예시
3차원 공간의 한 선분(Line segment)을 예로 들어봅시다.
1. **일반 내부($\text{int } C$):** 공집합 ($\emptyset$). 선분은 3차원에서 부피가 없기 때문입니다.
2. **아핀 헐($\text{aff } C$):** 선분을 포함하여 무한히 뻗어 나가는 직선.
3. **아핀 차원:** 1차원.
4. **상대적 내부($\text{relint } C$):** 양 끝점을 제외한 선분의 안쪽 부분.

이 개념을 통해 우리는 고차원 공간에 떠 있는 낮은 차원의 볼록 집합들도 수학적으로 엄밀하게 분석할 수 있게 됩니다.
