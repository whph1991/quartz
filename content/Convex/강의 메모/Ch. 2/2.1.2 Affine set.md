## 2.1.2 아핀 집합 (Affine Sets)

### 1. 정의 (Definition)
집합 $C \subseteq \mathbb{R}^n$ 안의 임의의 두 점 $x_1, x_2$에 대하여, 두 점을 지나는 **선(Line)** 이 다시 집합 $C$에 포함될 때, 이 집합을 **아핀 집합**이라고 합니다.
$$x_1, x_2 \in C, \quad \theta \in \mathbb{R} \implies \theta x_1 + (1-\theta)x_2 \in C$$
- **볼록 집합과의 차이:** 볼록 집합은 $\theta \in [0, 1]$ (선분)인 반면, 아핀 집합은 $\theta$가 **모든 실수**에 대해 성립해야 합니다. 따라서 ==모든 아핀 집합은 볼록 집합==이기도 합니다.
- 기하적인 해석, 수식적인 해석

### 2. 아핀 조합 (Affine Combination)
두 개 이상의 점 $x_1, \dots, x_k$에 대하여 다음을 만족하는 점을 **아핀 조합**이라고 합니다.
$$y = \theta_1 x_1 + \dots + \theta_k x_k \quad (\text{단, } \theta_1 + \dots + \theta_k = 1)$$
- 아핀 집합은 그 집합에 속한 점들의 모든 아핀 조합을 포함하는 집합입니다.

### 3. 선형 방정식의 해집합 (Solution set of linear equations)
아핀 집합의 가장 대표적인 예는 선형 방정식 시스템의 해집합입니다.
$$C = \{x \mid Ax = b\}$$
- 증명: 만약 $Ax_1 = b, Ax_2 = b$라면, 임의의 $\theta$에 대해:
    $A(\theta x_1 + (1-\theta)x_2) = \theta Ax_1 + (1-\theta)Ax_2 = \theta b + (1-\theta)b = b$
    이므로 해집합 $C$는 아핀입니다.
- 반대로, 모든 아핀 집합은 어떤 선형 방정식의 해집합으로 표현될 수 있습니다.

### 4. 서브스페이스(Subspace)와의 관계
아핀 집합 $C$에서 한 점 $x_0 \in C$를 빼면, 이는 항상 **서브스페이스(벡터 공간)** $V$가 됩니다.
$$V = C - x_0 = \{x - x_0 \mid x \in C\}$$
즉, 아핀 집합은 원점을 지나지 않을 수도 있는 "평행 이동된 서브스페이스"라고 이해할 수 있습니다.
