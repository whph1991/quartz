# 수학적 최적화 문제 (Mathematical Optimization)
수학적 최적화 문제(또는 간단히 최적화 문제)는 다음과 같은 형태를 가집니다

$$
\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \le b_i, \quad i = 1, \dots, m \end{aligned}
\tag{1.1}
$$

## 구성 요소 설명 
- **$x = (x_1, \dots, x_n)$**: 최적화 변수 (Optimization variable, decision variable)
- **$f_0 : \mathbb{R}^n \to \mathbb{R}$**: 목적 함수 (Objective function, cost function)
- **$f_i : \mathbb{R}^n \to \mathbb{R}, \quad i = 1, \dots, m$**: (부등식) 제약 함수 (Constraint functions)
- **$b_1, \dots, b_m$**: 제약 조건의 한계치 또는 경계 (Limits/Bounds)

## 최적해의 정의
벡터 $x^\star$가 제약 조건을 만족하는 모든 벡터 $z$ 중에서 가장 작은 목적 함수 값을 가질 때, 이를 최적(optimal) 또는 문제 (1.1) 의 해(solution)라고 합니다. 즉, 다음을 만족해야 합니다:

$$f_1(z) \le b_1, \dots, f_m(z) \le b_m \implies f_0(z) \ge f_0(x^\star)$$
