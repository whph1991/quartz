# Overview
볼록 최적화와 위상수학에서 **내부(Interior)**는 어떤 집합 안에 "여유 있게" 들어가 있는 점들의 집합을 의미합니다.

---
# Memo
### 1. 수학적 정의
집합 $C \subseteq \mathbb{R}^n$의 **내부(Interior)** 는 $\text{int } C$라고 표기하며, 다음과 같이 정의됩니다:

- **정의:** $\text{int } C = \{x \in C \mid B(x, r) \subseteq C \text{ for some } r > 0\}$
- **의미:** 점 $x$를 기준으로 아주 작은 반지름($r$)의 공을 그렸을 때, 그 공 전체가 집합 $C$ 안에 완전히 포함될 수 있다면, 그 점 $x$를 **내점(Interior point)**이라고 부릅니다.
-  **$B(x, r)$:** 점 $x$를 중심으로 하고 반지름이 $r$인 **유클리드 볼(Euclidean ball)** 을 의미합니다.

### 2. 직관적인 이해
- **"경계선에 있지 않음":** 내부는 집합의 '껍데기(Boundary)'를 제외한 알맹이 부분을 말합니다.
- **사방이 집합으로 둘러싸임:** 어떤 점에서 아주 미세하게 모든 방향으로 움직여도 여전히 집합 안에 있다면 그 점은 내점입니다.

### 3. 왜 Convex Optimization에서 중요할까?
최적화 문제를 풀 때 '내부'라는 개념은 매우 중요합니다.

1. **최적해의 위치:** 만약 최적해(Optimal solution)가 집합의 **내부**에 있다면, 그 지점에서의 기울기(Gradient)는 반드시 $0$이어야 합니다 ($\nabla f_0(x) = 0$).
2. **제약 조건:** 제약 조건 $f_i(x) \le 0$을 만족하는 영역(Feasible set)에서, $f_i(x) < 0$을 만족하는 영역이 바로 그 제약 조건의 **내부**가 됩니다.
3. **Interior-point Methods:** 이 책의 후반부에서 배우는 알고리즘 이름 자체가 '내부점 방법'입니다. 이는 경계선을 따라 움직이는 대신, 집합의 **내부**를 가로질러 최적해를 찾아가는 방식입니다.

### 4. 주의할 점: 낮은 차원의 문제
**상대적 내부(Relative Interior)** 와 비교해 보세요.
- 3차원 공간에 떠 있는 **종이 한 장(2차원 평면)**을 생각할 때:
    - **$\text{int } C$ (일반 내부):** 공집합($\emptyset$)입니다. 종이는 두께가 없어서 아무리 작은 공($B(x,r)$)을 잡아도 종이 밖으로 튀어나가기 때문입니다.
    - **$\text{relint } C$ (상대적 내부):** 종이의 테두리를 제외한 안쪽 면입니다. (종이가 놓인 그 평면 안에서만 공을 생각하기 때문입니다.)
